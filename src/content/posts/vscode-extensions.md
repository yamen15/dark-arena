## مقدمة

VS Code من أشهر محررات الكود، وهذه أفضل الإضافات التي أنصح بها.

## الإضافات المُوصى بها

- **Arabic Language Pack** - لتعريب الواجهة
- **Prettier** - لتنسيق الكود تلقائياً
- **GitLens** - لتتبع التغييرات في Git
- **Error Lens** - لعرض الأخطاء مباشرة في السطر
